# 0x800 — dev notes

Hexadecimal 2048 played on a hex grid. Tiles slide six ways (NE, E, SE, SW, W,
NW) instead of the usual four, and values/scores are displayed in hex
(`0x…`) with a toggle to decimal.

## Structure

- `index.html` — shell markup: header (logo + home link, score/best panels),
  meta row (moves/time/undos/seed), stage (board + overlay), log, and the
  hex control pad + action buttons.
- `styles.css` — theming via CSS custom properties (`light`, `dark`,
  `contrast`), hex tile/cell geometry using `clip-path: polygon(...)`,
  animations for slide/pop/spawn/nudge.
- `src/main.js` (module entry) — game logic, input handling, rendering.

## Navigation

The header logo now includes a small `home` link (`<a href="/">`) so players
can get back to the games index without using the browser back button. It's
styled as a muted, uppercase label above the `0x800` wordmark and brightens
on hover/focus.

## Theming

Theme is resolved before first paint via an inline script reading
`localStorage['0x800:prefs'].theme` (`auto` | `light` | `dark` | `contrast`)
and setting `data-theme` on `<html>` to avoid flash-of-wrong-theme.

## Tile palette

Each exponent (1, 2, 4, 8, 10, 20, … up to 8000 hex) has a dedicated
`--tile-N` / `--tile-N-fg` pair per theme, contrast-checked in
`test/palette.test.js` (>= 4.5:1).

## Board geometry

Hex cells/tiles are positioned with `--tx`/`--ty` custom properties consumed
by `translate3d(calc(var(--hex-size) * var(--tx)), ...)`, letting JS just set
axial-derived offsets without recomputing pixel math per frame.
